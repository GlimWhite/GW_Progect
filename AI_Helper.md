# Структура и описание проекта (AI Helper)

Этот файл содержит подробное описание структуры проекта, расположения папок и функций ключевых файлов. Он поможет быстро сориентироваться в проекте.

---

## 1. Общая структура проекта

### `/Base`
Корневая папка проекта. Содержит основные данные: интерфейс (UI), эффекты, модели, текстуры, карты и так далее.

---

## 2. Описание папок и файлов

### `/Base/Effects`
Скрипты эффектов (оружия, моделей, окружения). Хранятся в формате `.efx`.

### `/Base/Ext_data`
Характеристики оружия, NPC и транспорта.

### `/Base/GFX`
Графические элементы (спрайты, иконки), разбитые по папкам. Ранее описанные эффекты в `.efx` ссылаются на эти файлы.

### `/Base/HUD`
Элементы интерфейса, вынесенные из папки `GFX` для удобства обработки.

### `/Base/Maps`
Игровые карты в формате `.bsp`.

### `/Base/Menu`
Файлы меню, вынесенные из `GFX` в отдельную папку для удобства редактирования.

### `/Base/Models`
Игровые модели персонажей, оружия и объектов.

### `/Base/Scripts`
Скрипты карт и триггеров (ICARUS).

### `/Base/Shaders`
Шейдеры, используемые в проекте. Основные шейдеры находятся в следующих файлах:
*   `/Base/Shaders/1. NewMenu.shader` — шейдеры для работы с меню (`/Base/UI/1.Menu/`).
*   `/Base/Shaders/2. Effects_Redux.shader` — переопределение и добавление новых эффектов, которые берут скрипты из `/Base/Effects/`.
*   `/Base/Shaders/3. Graphics.shader` — шейдеры с улучшенной графикой (как в меню, так и в игре).
*   `/Base/Shaders/4. None.shader` — файл для удаления лишних шейдеров и добавления прозрачностей.
*   *...остальные шейдеры предназначены для карт.*

### `/Base/Textures`
Текстуры, используемые в проекте.

---

## 3. Подробная структура интерфейса (`/Base/UI/`)

Папка `/Base/UI/` содержит настройки меню проекта, разбитые по папкам для удобства редактирования.

### Папка `/Base/UI/1.Menu/`
Главное меню и меню настроек:
*   `0_Main.menu` — загрузочный экран проекта;
*   `1_Menu.menu` — главное меню проекта;
*   `2_NewGame.menu` — меню «Новая игра»;
*   `3_LoadGame.menu` — меню загрузки игры;
*   `4_Controls.menu` — меню управления;
*   `5_Setup.menu` — меню настроек графики;
*   `6_Quit.menu` — меню выхода из проекта;
*   `7_Character.menu` — меню выбора и настройки персонажа;
*   `8_Saber.menu` — меню выбора светового меча;
*   `9_Global.menu` — глобальные параметры для всего меню;
*   `10_Mods.menu` — меню модов;
*   `11_Warning.menu` — меню ошибок.

### Папка `/Base/UI/2.In_game_Menu/`
Меню, используемое внутри игры:
*   `0_Global.menu` — глобальные параметры для всего меню;
*   `1_Main.menu` — главное меню;
*   `2_Save.menu` — меню сохранения в игре;
*   `3_Load.menu` — меню загрузки игры;
*   `4_Controls.menu` — меню управления;
*   `5_Setup.menu` — меню настроек графики;
*   `6_Quit.menu` — меню выхода из игры в главное меню;
*   `7_Saber.menu` — меню выбора меча;
*   `8_SaberStyle.menu` — меню выбора стиля меча;
*   `10_MissionFailed.menu` — меню при проваленной миссии;
*   `11_LoadDead.menu` — меню при смерти игрока.

### Папка `/Base/UI/3.HUD/`
Интерфейс внутри игры:
*   `1_Interface.menu` — интерфейс игры;
*   `2_Global.menu` — глобальные параметры для всего меню.

### Папка `/Base/UI/4.Mission/`
Меню для перехода с миссии на миссию:
*   `0_MissionSelect.menu` — выбор миссий первого порядка;
*   `1_MissionSelect1.menu` — выбор миссий второго порядка;
*   `2_MissionSelect2.menu` — выбор миссий третьего порядка;
*   `3_MissionSelect3.menu` — выбор миссий четвертого порядка;
*   `4_VictoryMassage.menu` — проигрывается после прохождения каждой успешной миссии.

### Папка `/Base/UI/OtherMenu/`
*   `Error.menu` — ошибки в игре;
*   `LoadScreen.menu` — загрузочный экран;
*   `Warning.menu` — выдает окно, если не сохранили настройки в игре.

### Папка `/Base/UI/Pad/`
Настройки планшета меню:
*   `ForcePowers.menu` — сила;
*   `Mission.menu` — цель миссии;
*   `Moves.menu` — движения;
*   `Weapons.menu` — оружие.

### Папка `/Base/UI/Select/`
Меню выбора очков силы, оружия и помощи:
*   `ForceHelp.menu` — окно помощи при выборе силы;
*   `ForceSelect.menu` — меню распределения очков силы;
*   `ForceStatus.menu` — окно статуса силы;
*   `GoToTier.menu` — выбор следующей фазы игры;
*   `WeaponHelp.menu` — меню помощи при выборе оружия;
*   `WeaponSelect.menu` — меню выбора оружия.

### Файлы распределения меню (в корне `/Base/UI/`)
*   `HUD.txt` — меню для папки `/Base/UI/3.HUD/`;
*   `InGame.txt` — меню для папки `/Base/UI/2.In_game_menu/`;
*   `Menu.txt` — меню для папки `/Base/UI/1.Menu/`;
*   `Tier1.txt`, `Tier2.txt`, `Tier3.txt` — меню для папки `/Base/UI/4.Mission/`.
